# Meteor Seed Utils

Required: Meteor Client 1.21.4 build #25 or newer

## Capabilities
- manual input of structures for lifting (with version of structure in case of default ones)
- storage of structures
- copy/paste structures to clipboard
- lifting of structures
- structure seeds to random world seeds from lifting
- copy/view structure and random world seeds
